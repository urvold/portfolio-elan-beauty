# ÉLAN BEAUTY

Самостоятельный концептуальный проект для портфолио. React 19, TypeScript, Vite, React Router, Lucide; CSS без тяжёлой анимационной библиотеки. Весь интерфейс на русском.

## Запуск

Требуется Node.js 22+.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://localhost:5173/portfolio-elan-beauty/).

```sh
npm test
npm run build
npm run preview
```

Production-файлы находятся в `dist`. Базовый путь: `/portfolio-elan-beauty/`. Конфигурация Vite создаёт отдельные HTML-точки входа для всех 19 маршрутов и `404.html`. Прямые ссылки и обновление известных страниц обслуживаются GitHub Pages без SPA-редиректа. Локальный адрес также содержит базовый путь.

## Структура

- `src/data.ts`: типы, 7 процедур, 4 вымышленных специалиста, функции расписания и подбора.
- `src/main.tsx`: страницы, общая навигация, каталог с фильтрацией, галерея, запись и опрос.
- `src/style.css`: дизайн-система, адаптивные композиции, CSS motion, reduced motion.
- `tests/domain.test.ts`: инварианты каталога, расписание, правила рекомендаций.
- `public/images`: локальные оптимизированные фотографии; источники — `SOURCES.md`.

## Страницы

`/`, `/services`, `/services/:id`, `/team`, `/team/:id`, `/gallery`, `/about`, `/booking`, `/ritual`, `/contacts`, неизвестные маршруты → 404.

## Демонстрационная запись

Выбор услуги → совместимый специалист → календарь → подтверждение. Выбранные значения сохраняются при возврате. Смена услуги сбрасывает несовместимого специалиста и время. Понедельник — выходной. Часы 10:00–20:00, начало каждые 30 минут, исключены интервалы, не вмещающие процедуру, прошедшее время и детерминированно занятые интервалы. Даты вычисляются локально относительно текущего дня, показаны текущий и два следующих календарных месяца. При подтверждении доступность проверяется повторно. Итоговая цена фиксирована каталогом и не зависит от мастера. Нет API, реальной брони, оплаты, форм персональных данных и хранения пользовательских ответов.

## Подбор

Три вопроса: настроение, время, направление. Направление и максимальная длительность фильтруют каталог. Совпадение настроения повышает приоритет; далее сортировка по длительности. До трёх результатов. При отсутствии совпадений показано объяснение и возврат к ответам. Медицинские рекомендации отсутствуют.

## Проверки и ограничения

`npm test` проверяет доменную логику; `npm run build` проверяет TypeScript и production-сборку. Браузерное тестирование полного сценария, визуальная проверка на 320/375/390/430/768/1024/1440 и Lighthouse требуют доступного браузера и пока не подтверждены. Адаптивные правила предусмотрены для этих диапазонов. Целевые показатели Lighthouse не являются результатами измерения.

Для финальной QA: пройти запись и возврат между всеми шагами; сменить услугу и мастера; проверить недоступные даты; пройти опрос с результатом и без совпадений; проверить все маршруты, мобильное меню, галерею (Escape, стрелки, Tab), отсутствие горизонтального скролла и ошибок консоли. Перед публичным запуском задать абсолютные canonical/OG URL для выбранного домена и повторить браузерный аудит. Шрифты размещены локально в `public/fonts` (источник — Google Fonts).

## GitHub Pages

Репозиторий: https://github.com/urvold/portfolio-elan-beauty

Адрес публикации: https://urvold.github.io/portfolio-elan-beauty/

Workflow `.github/workflows/pages.yml`: при push в `main` выполняет `npm ci`, шесть тестов, production-сборку и проверку всех HTML-точек входа, ресурсов и отсутствия сбора персональных данных; затем загружает артефакт и публикует через GitHub Pages. Node.js 24, минимальные права `contents: read` для сборки, `pages: write` и `id-token: write` для публикации. Секреты проекта не требуются. В Settings → Pages выбран источник GitHub Actions, HTTPS включён. Порядок проверки публикации описан в `PUBLISHING.md`.
